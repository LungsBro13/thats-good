# Brand

Traced from the original logo artwork into vector files, so they stay sharp at any size.

| File | Use |
|---|---|
| `golfer-dark.svg` | Dark green golfer, green flag and ball: on light backgrounds |
| `golfer-light.svg` | Off-white golfer, green flag and ball: on dark green |
| `golfer-on-green.svg` | Dark golfer, white flag and ball: on grass green |
| `app-icon-1024.png` | App Store icon (iOS rounds the corners itself) |

Colours: a golf course. Only greens and sand.

| Name | Hex | Use |
|---|---|---|
| Deep rough | `#0E2A1F` (stripe `#133524`) | Dark cards, text, tab bar, splash |
| Fairway | `#3A9D3C` (stripe `#44A846`, pressed `#23692A`) | Main buttons, live cards, Wrapped slides |
| Green | `#DDF1C9` (stripe `#D2EBBC`) | Light cards |
| Fringe | `#C8E6B0` | Highlights, avatars |
| Rough text | `#1F4A33` | Dark green text on light greens |
| Bunker | `#E9D6A5` | Sand highlights, first place, bunker shapes |
| Light sand | `#F1E4C3` | "Work on next", sand cards |
| Wet sand | `#9C6B2E` / `#B88B4A` | Losses (L), sand icons |
| Sand text | `#5C4320` / `#7A5A25` | Text on sand |
| Off-white | `#F3F6F2` | Page background |

Mowing stripes: alternate two shades of the same green in vertical bands (36 to 48 pt wide).
Corners: cards 14 to 16 pt, buttons 12 pt, chips 5 to 8 pt.
Title: Cormorant Garamond SemiBold (the logo's font), capitals, letter spacing 0.14 em. Bundled in `ThatsGood/Fonts` (SIL Open Font License). Body: the iPhone's rounded system font.
